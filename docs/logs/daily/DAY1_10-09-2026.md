## Key decisions

- **`numpy<2` pinned.** Python is 3.11.16, so per §0.5 current versions were
  taken for everything — except numpy, which `neurokit2==0.2.7` (pinned by the
  brief) predates the ABI break of. Recorded in `docs/logs/tasks/5-mlops.md` as
  a consequence of the neurokit2 pin, not of the Python version.
- **Grad-CAM hand-rolled**, not the `grad-cam` package — ~40 lines of hooks, and
  inlining it preserves the self-contained-script convention that makes a Kaggle
  kernel the same file with different path constants.
- **The brief's ECG frequency-band annotation is wrong and is corrected**, not
  followed. Scales `arange(20, 501)` with `cmor1.5-1.0` at 2000 Hz give
  **4.0–100.0 Hz**, not the "≈0.5–40 Hz" the brief states — verified by running
  `pywt.cwt`. The *scales* are kept exactly as specified (they are the explicit
  part of the spec, and §10.1 requires scale ranges be held fixed across
  wavelets); only the Hz annotation is corrected, and the measured numbers are
  what go in the paper. Full working in `docs/logs/tasks/2-features.md`.
- **`db4` → `gaus4` independently re-verified**, not taken on trust:
  `pywt.cwt(sig, scales, "db4", ...)` really does raise
  `AttributeError: ... object has no attribute 'complex_cwt'` on PyWavelets
  1.8.0, and `db4` really is absent from `pywt.wavelist(kind="continuous")`.
