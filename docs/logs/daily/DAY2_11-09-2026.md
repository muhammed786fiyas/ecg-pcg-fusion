## Work done

yesterday's serving code.** The CWT boundary-artifact fix (reflect-padding) went
into `scripts/features/01_scalogram.py` on day 1, but the two serving copies of
the transform — `scripts/serving/app.py` and `scripts/serving/gradio_demo.py` —
were written before it and never updated. Compared against the stored training

| segment | ECG mean abs diff | ECG max | PCG mean abs diff |
|---|---|---|---|
| a0001_seg000_orig | 58.84 / 255 | 239 | 0.32 |
| a0200_seg003_orig | 62.14 / 255 | 242 | 0.21 |
| a0405_seg000_orig | 55.99 / 255 | 241 | 0.20 |

So the served model was fed artifact-ridden ECG scalograms unlike anything it
trained on. Fixed in both files. `tests/test_serving_parity.py` now compares the
serving transform to the training memmap for real segments (6 tests; they skip in
CI, where the data is absent) — both files now match within one uint8 level.
**107 tests pass**, ruff clean.

**Built the public Space for `cross_attn_resnet18`.**
`scripts/serving/hf_space_app.py` is the Space's `app.py`;
`scripts/serving/build_hf_space.py` stages it (and uploads with `--upload`):
- **Weights: fold 0**, chosen by inner-*validation* AUC (0.9745, highest of the
  five). Test AUC is never read by the selection.
- **Record-level, like the paper:** R-peak-centred 3 s windows exactly as in
  training, one probability per window, mean aggregation (Contribution 3's best).
- Grad-CAM from the last conv of each ResNet branch (a 7 x 7 map, coarse by
  construction), with the frequency axis **labelled in Hz** so it cannot be read
  upside down — the day-1 Grad-CAM inversion bug, designed out.
- Slim checkpoint loaded with `weights_only=True`; `torchvision` built with
  `weights=None` so the Space never downloads ImageNet weights it would
  overwrite.
- Examples: `a0038` (normal) and `a0001` (abnormal), the first of each class by
  record ID in **fold 0's held-out test partition** — never data the deployed
  model trained on, and chosen before looking at its predictions.

**Staged Space tested end-to-end locally:**
- `abnormal_a0001` -> abnormal, p = 0.998, 11 windows, 3.8 s
- `normal_a0038` -> **abnormal, p = 0.584, 10 windows — wrong**

## Key decisions

- **Keep the misclassified example.** Swapping in a normal record the model gets
  right would be choosing examples by outcome. Instead the demo now shows the
  ground truth next to the prediction for bundled examples, and names the model's
  usual error: calling normal records abnormal (patient-level specificity 0.77 vs
  sensitivity 0.93 in cross-validation).
- **One fold's weights, not a 5-fold ensemble** — simpler and faster on a free
  CPU Space. Discussed below.

## Discussed-not-decided

- **Deploy a 5-fold ensemble instead?** It would remove the single-fold choice
  entirely, at 5x the model size (~440 MB) and slower CPU inference.
- **A licence for the Space and repo.** None is set; that is the owner's call.

## Observation, not a finding

On the demo's rendered window, the ResNet model's ECG attention sits around 5 Hz
(matching day 1's result for `cross_attn_fusion`), but its PCG attention sits
near 16 Hz — below the classic S1/S2 band, unlike `cross_attn_fusion` (median
28 Hz). One window, from a misclassified example: a lead for the planned
Grad-CAM-on-ResNet analysis, not something to report.

## Update — afternoon

**A HuggingFace write token was pasted into `README.md`.** While logging in with
`hf auth login`, a right-click paste landed in the open editor tab as well, and
the token ended up as the last line of the tracked README. Caught before any
commit: zero token-shaped strings anywhere in git history, none in any other
file, none in the Space staging folder. Removed by restoring README from the
last commit (it was the only change). Because it appeared in a file and in the
session transcript, the owner was advised to revoke it and issue a new one.

Guards added, since commits are now pushed immediately and a committed secret is
public within seconds:
- a **local pre-commit hook** (`.git/hooks/pre-commit`) that blocks any commit
  whose staged changes add a HuggingFace, GitHub or Kaggle-key-shaped string.
  Proven to block, using a fake token generated at runtime. Hooks are not
  versioned, so a fresh clone needs it reinstalled;
- `tests/test_no_secrets.py`, the versioned backstop that scans every tracked
  file, locally and in CI.

**The Space upload was refused: HTTP 402 Payment Required.** HuggingFace now
requires a PRO subscription to host Gradio or Docker Spaces, even on the free
`cpu-basic` hardware; only static Spaces stay free. Nothing was created on the
account (verified). The staged Space is otherwise ready. `build_hf_space.py`
now reports a 402 as a clear `QC FAIL` rather than a stack trace, which had
also been hidden behind a zero exit code by the output pipe.
